# Python Vibe Coding Challenge

## Challenge Description

You have **24 hours** to vibe code the best Python project you can create!

There are no assigned topics or required project types. Use AI tools, your programming knowledge, and your creativity to develop something impressive.

Students from **CS15, CS25, and CS35**, across morning and afternoon classes, will compete against one another.

Whether you create a useful tool, an entertaining game, or a visually stunning experience, the choice is yours!

## Competition Categories

Your teacher will select one winning project in each category:

- **Most Useful Program:** Solves a problem, improves a task, or provides something practical.
- **Most Fun Program:** Offers an entertaining, engaging, or enjoyable experience.
- **Most Visually Interesting Program:** Stands out through graphics, interfaces, animations, or visual creativity.

**Prize:** Each category winner receives a **donut of their choice**!

## Student Choice Awards

Students will vote for their favourite projects from across the competing classes.

The **top 10 student-voted projects** will each receive a **sticker of their choice** from the teacher's sticker collection!

## The Rules

- [ ] Develop your project within **24 hours**.
- [ ] Create your project primarily using **Python**.
- [ ] Use AI coding tools if you wish to help plan, generate, debug, and improve your code.
- [ ] Use any Python libraries or frameworks you wish, including ones not listed above.
- [ ] Keep your project appropriate for a school environment.
- [ ] Submit a functional project that is ready to demonstrate.
- [ ] Be prepared to explain what your project does and demonstrate its features.
- [ ] Make the project your own creation, even if AI helps you build it.
